유료 서비스 (플러스챗 등) 공유 규정

플러스챗(Plus Chat) 프라이빗 메시지, 전용 피드, 유료 멤버십 라이브 캡처 등은 결제 회원만을 위한 독점 콘텐츠입니다. 트위터(X), 인스타그램, 커뮤니티 등에 캡처본 또는 원본을 재업로드하는 것은 이용약관 위반 및 저작권 침해에 해당합니다.

공개 공식 SNS (공유 가능)

리센느 공식 X(@resceneofficial), 공식 인스타그램, 유튜브 커뮤니티, 틱톡 등 공개 계정에 정식 포스팅된 사진은 출처를 명시하고 자유롭게 팬 활동 및 RT/공유가 가능합니다.

GitHub Pages에 배포 및 유지보수하는 방법

  1. 본 파일(index.html)을 GitHub의 새 Repository (예: rescene-source-finder)에 업로드합니다.
  2. 플러스챗 사진들을 [DB 관리도구]에서 추가한 뒤, [JSON 내보내기]를 눌러 database.json 파일로 저장합니다.
  3. 저장한 database.json을 같은 GitHub 저장소 루트 디렉토리에 커밋하면 자동으로 전 세계 팬들이 최신 DB를 기반으로 조회할 수 있습니다!
  4. GitHub Repository Settings → Pages 메뉴에서 배포 브랜치(main / root)를 선택하면 완전히 무료 웹사이트가 즉시 생성됩니다.
